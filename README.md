# Excel Organizer V2

Excel Organizer V2 is a work-in-progress desktop application designed to
clean and organize Excel files through a simple graphical interface.

## Current Progress

The application currently supports:

- Opening Excel files
- Displaying Excel data in a table
- Selecting cleaning operations through a graphical interface
- Removing empty rows
- Removing duplicate rows
- Cleaning extra spaces from text cells
- Previewing the cleaned data before applying changes
- Applying or cancelling the proposed changes

## Technologies

- Python
- PySide6
- pandas
- openpyxl

## Project Structure

- `core/` – Excel processing and cleaning logic
- `ui/` – graphical interface
- `tests/` – tests for the cleaning functionality
- `main.py` – application entry point

## Planned Features

The project is still under development.

Planned improvements include:

- Removing empty columns
